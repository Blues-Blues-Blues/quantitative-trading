# 因子公式修改历史

本文件记录因子层公式及缺失值口径的变更。交易策略的 ES、PS、XS、状态机和仓位规则未在本次调整。

## 2026-09-28：OBI 改用最优买卖档队列失衡

- **原来是什么样**：`OBI = (五档委买量之和 - 五档委卖量之和) / (五档委买量之和 + 五档委卖量之和 + ε)`。买一与买五的挂单量等权。
- **为什么改**：Gould 与 Bonart 的[队列失衡研究](https://arxiv.org/abs/1512.03492)使用最优买卖档队列量预测下一次中间价变动。当前项目的分钟末快照适合计算这一静态队列失衡量；深档大量挂单可能掩盖最优档供需。该研究基于美股，改动本身不等于已经证明 A 股收益改善。
- **改成了什么样**：`OBI = (bid1_v - ask1_v) / (bid1_v + ask1_v)`，仅在两档量有效、非负且总量大于零时计算；否则为 `NaN`，由 OFSS 的有效权重重归一化处理。这是分钟末队列失衡，**不是**需要连续事件的原始 OFI。
- **在哪个文件夹**：`indicators/microstructure.py`；对应回归用例在 `tests/test_features.py`。公式变更使 `indicators/feature_engine.py` 的特征缓存版本从 4 升至 5。

## 2026-09-28：无撤单来源时不再给 OFSS 撤单加分

- **原来是什么样**：逐笔表中没有 `is_cancel=True` 记录时，`Cancel_Ratio = 0`，因此 `cancel_score = clip((0.2 - 0) / 0.2, -1, 1) = +1`，以默认 0.2 权重进入 OFSS。
- **为什么改**：当前 `data/l2_loader.py` 的真实逐笔成交加载器把 `is_cancel` 固定为 `False`；没有撤单事件来源不代表真实撤单量为零。原公式会把“未知”错误奖励为“完全稳定”。Cont、Kukanov 与 Stoikov 的[订单流研究](https://arxiv.org/html/1011.6402v3)也明确区分成交与撤单等盘口事件。
- **改成了什么样**：若整张逐笔输入表没有撤单事件，`Cancel_Ratio = NaN`；OFSS 沿用原有缺项权重重归一化。若有撤单事件来源，未发生撤单的分钟仍按 `0` 处理。撤单率本身和 `cancel_score` 的数学式不变。
- **在哪个文件夹**：`indicators/microstructure.py`；对应回归用例在 `tests/test_features.py`。同次变更使用上述特征缓存版本 5。

## 2026-09-28：PSS 纳入上下影线方向

- **原来是什么样**：`PSS = 0.5 × (close-open)/(high-low+ε) + 0.5 × (2×窗口收盘位置-1)`。只使用实体和近 60 分钟收盘位置；同样的实体、收盘位置可能掩盖当前 K 线高位抛压或低位承接。
- **为什么改**：[Qlib Alpha158 官方实现](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)将上影线与下影线长度分别作为标准 K 线结构特征。本项目把两者合成为有方向的影线分，保留原有窗口位置项。合成权重是本项目的候选设计，尚未证明预测能力优于原式。
- **改成了什么样**：`upper=(high-max(open,close))/(high-low+ε)`，`lower=(min(open,close)-low)/(high-low+ε)`，`shadow=lower-upper`；`PSS=clip(w_body×body + w_shadow×shadow + (1-w_body-w_shadow)×pct_score, -1, 1)`。默认 `w_body=0.5`、`w_shadow=0.25`、窗口位置权重 `0.25`；权重非负且和不超过 1。一字无波动时影线分与位置分仍为 0。
- **在哪个文件夹**：`indicators/microstructure.py`；对应回归用例在 `tests/test_features.py`。同次变更使用上述特征缓存版本 5。当前交易评分不读取 PSS，故此项只改变特征值，不改买卖判定。
